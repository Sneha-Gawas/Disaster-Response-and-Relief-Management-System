=================================================
1. USGS EARTHQUAKE DATASET
=================================================

Source:
United States Geological Survey (USGS)

Purpose:
Provides real-time and historical earthquake information worldwide.
Used for disaster monitoring, hotspot detection and anomaly detection.

Dataset Type:
Public API / CSV Feed

Key Attributes:

- place
  Location where earthquake occurred

- magnitude (mag)
  Strength of earthquake

- latitude
  Geographic latitude

- longitude
  Geographic longitude

- depth
  Depth of earthquake beneath surface

- time
  Event occurrence timestamp

Project Usage:

1. Real-time disaster monitoring
2. HDBSCAN hotspot detection
3. Isolation Forest anomaly detection
4. Dashboard visualization
5. Earthquake severity assessment

Machine Learning Usage:

Input Features:
- magnitude
- latitude
- longitude
- depth

Algorithms:
- HDBSCAN
- Isolation Forest

2. NOAA STORM EVENTS DATASET
=================================================

Source:
National Oceanic and Atmospheric Administration (NOAA)

Purpose:
Contains historical records of weather-related disasters and severe
storm events across the United States.

Dataset Type:
CSV Dataset

Key Attributes:

- EVENT_TYPE
  Type of weather event

- INJURIES_DIRECT
  Number of directly injured people

- DEATHS_DIRECT
  Number of direct fatalities

- DAMAGE_PROPERTY
  Estimated property damage

- DAMAGE_CROPS
  Estimated crop damage

- STATE
  State where disaster occurred

Project Usage:

1. Disaster impact analysis
2. Resource requirement estimation
3. Relief fund estimation
4. Historical disaster pattern analysis

Machine Learning Usage:

Input Features:
- injuries
- deaths
- property_damage
- crop_damage

Algorithms:
- XGBoost Resource Prediction
- XGBoost Fund Prediction

=================================================

Key Attributes:

  Type of declaration

- incidentType

- state
  State affected

- designatedArea
  County or affected area

- incidentBeginDate
  Disaster start date

Project Usage:

1. Historical disaster records
2. Disaster classification
3. Resource planning
4. Fund planning
5. Disaster analytics

Machine Learning Usage:

Input Features:
- disaster_type
- location
- incident_date

Algorithms:
- XGBoost Resource Prediction
- XGBoost Fund Prediction

5. RESOURCE DATASET
=================================================

Generated From:
NOAA + FEMA + Feature Engineering

Purpose:
Training dataset for disaster resource prediction model.

Input Features:

- magnitude
- affected_population
- property_damage
- injuries
- deaths

Target Features:

- food_kits
- medical_kits
- shelters_required
- rescue_teams
- water_units

Project Usage:

Predicts required disaster relief resources for affected regions.

Machine Learning Algorithm:

XGBoost MultiOutput Regressor

Outputs:

- Food Kits Required
- Medical Kits Required
- Shelters Required
- Rescue Teams Required
- Water Supply Required
